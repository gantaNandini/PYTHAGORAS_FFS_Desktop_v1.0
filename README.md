# PYTHAGORAS FFS — Desktop 3.0 (ATLAS Part 9, KPTC / KPSCL1 / KPSCL2)

## What is new in 3.0
* **Surface crack, infinite length** — KPSCL1 (Annex 9B.3.2 / 9C.3.2, fourth-order polynomial) and KPSCL2 (9B.3.3 / 9C.3.3, arbitrary stress,
  weight function). Choose them in the Crack Case Library (Surface Cracks) or with the *Through-wall stress distribution* drop-down on the Loads page.
* **Stress profile table** (50 points, paste from Excel) for the arbitrary distribution; residual column usable via USER_PROFILE.
* **Remaining Life tab** — calculated life, required life × margin, allowable life, inspection interval and number of inspections; geometry-independent.
* Project files are format 4 (older .pfs files still open). Dual units, FAD, residual stress and the Level 3 sensitivity study work for all cases.
* Tests: `tests/oracle.json` now has 360 scenarios (KPTC + KPSCL) generated by the Python engine; `npm test` also runs `tests/test_model.mjs`.
* Regenerate with `python tools/gen_data.py <ATLAS_API579_PART9>` and `python tools/oracle_gen.py <ATLAS_API579_PART9>` (new package layout).

Below: original description (KPTC / RPTC).


Fitness-for-Service crack assessment to **API 579-1/ASME FFS-1 2021, Part 9** for a plate with a central through-wall crack
(Annex 9B.3.1 KPTC / 9C.3.1 RPTC): Level 2 FAD, limiting flaw size, fatigue crack growth, remaining life and inspection
interval, and **Level 3** (Method A sensitivity / partial safety factors, Method D ductile tearing).

Version 2.0 brings **everything in the ATLAS R8 Excel/Python package into the desktop application**: every input sheet,
every database, every result sheet and plot. The calculation engine is the ATLAS Python engine ported to JavaScript and
checked against the original (see *Verification*).

## New in 2.2/2.3 — guided use and built-in Help
* **Every input step has a slim header** (step number, name, standard reference). **Show tips** opens a short explanation of what to
  enter (hidden by default, remembered); **Help** opens the manual at that topic. **Back / Next** buttons walk through the steps.
* **Start page**: "Start with the reference example" opens a complete, already-filled case; first-time banner explains the workflow.
* **Results begin with "The result in plain words"**: acceptable now or not, limiting crack size and life, the life criterion,
  allowable life and inspection interval, and any Level 3 warning — in a few sentences.
* **Help (F1 or Help menu)** contains the complete *ATLAS KPTC/RPTC Help & User Tutorial* (17 topics, searchable, with the worked
  numerical example, formulas, glossary, troubleshooting and checklists). F1 and the "?" buttons open the topic for the page you are on.
  Help is generated from the manual into `src/help/help.generated.js` (nothing is needed at run time). To change the text, edit the Word manual in
  `tools/help_source/` and run `python tools/gen_help.py tools/help_source/ATLAS_KPTC_RPTC_Help_User_Tutorial.docx` (needs pandoc + beautifulsoup4).
  The Excel/Python-only passages of the manual are accompanied by an "In this desktop application" note.
* Line plots use round-number axes and show a small table of start / middle / end values beside the chart; the square chart shrinks to fit short windows.
* The Plots page has a drop-down with ◀ ▶ buttons to choose among the 14 plots; log-log plots use clean decade ticks.
* All charts are **small squares** (440 px; 300 px for the load-history preview); the Plots page shows an explanation beside each plot, and
  *Save as PNG* writes a square image.

## Units
**SI** (mm, MPa, MPa√m, °C) or **FPS** (in, ksi, ksi√in, °F) from the toolbar. Unlike the Excel template the application converts
every value already typed, including Paris C and the J-R coefficient, so switching never changes the physics. Results, plots,
exports and the printed report follow the selected system.

## Files
* `.pfs` — analysis file (JSON, format 3). Files from the earlier simplified versions (≤ 1.3) cannot be opened; use the Excel import.
* **File → Import ATLAS Input Workbook (.xlsx)** reads `KPTC_Constant_Input.xlsx` / `KPTC_Variable_Input.xlsx` (SI or FPS) directly.
* **Export Results (Excel)** writes the ATLAS result sheets plus an Inputs sheet; **Export Crack Growth History (CSV)**; **Print / Save as PDF**.
* Undo/redo, crash recovery, recent files and project information (Cover sheet fields) are included.

## Engineering notes (from ATLAS)
Material database strengths are specified minimum values; confirm against the governing specification and heat treatment.
`REFERENCE_CS_350` is the ATLAS regression dataset, not a real material. Project-entered toughness, strength or growth constants
require *Project data status = APPROVED*. KPTC has no non-linear stress solution, so non-uniform residual profiles are applied as a
conservative uniform envelope. The 0.5 inspection fraction and the Level 3 partial safety factors are illustrative project defaults,
not API 579 requirements. Results must be reviewed by a qualified engineer.
